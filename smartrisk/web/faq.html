FAQ

Common questions, answered simply.

A quick guide to how the scanner works and what its results mean.

Do I need an account to run a scan?

No. The scanner is intentionally open. You can paste a contract address and start a scan without signing in.

Do I need to choose the network?

No. SmartRisk detects the network automatically from the contract address across the supported networks.

Does a low-risk result mean the token is safe?

No. A report is a technical assessment at the time of the scan, not a guarantee of future behavior, price, liquidity, or project intent.

What if SmartRisk cannot find enough data?

The report should show limited coverage or unknowns rather than silently filling the gaps with a safe result.

Can SmartRisk detect every honeypot?

No scanner can guarantee that. SmartRisk uses code analysis and state-based checks to find important patterns, but contracts can behave differently over time or under conditions the system cannot reproduce.

How long does a scan take?

It depends on the contract, network data, provider response times, and the analysis stages that can be completed. Simple scans may finish quickly; deeper state-based checks can take longer.

Can I report a result that looks wrong?

Yes. Send the contract address, network if known, and the part of the report you disagree with to support@smartrisk.io.

Where should I report a security vulnerability?

Please use security@smartrisk.io for security issues rather than posting sensitive details publicly.
