Automatic detection

There is no network selector on the scanner. SmartRisk checks the configured networks for the contract address and uses the network that resolves successfully for the analysis.

What support means

Network support covers the core scan pipeline: chain access, anchoring, state-fork execution where available, trading routes, intelligence, evidence, and unified reporting. Individual data providers can still have temporary outages or incomplete historical coverage.
