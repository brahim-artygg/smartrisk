Quick start

curl -X POST https://your-domain.example/v1/api/batches \
  -H 'Content-Type: application/json' \
  -H 'X-API-Key: sr_live_...' \
  -H 'Idempotency-Key: batch-001' \
  -d '{
    "items": [
      {"address": "0x...", "chain_id": "1"},
      {"address": "0x...", "chain_id": "8453"}
    ]
  }'

A batch is asynchronous. Poll /v1/api/batches/{batch_id}, or fetch paginated results when you need them.
