Security

Security is part of the product.

SmartRisk handles account data, scan infrastructure, and on-chain analysis. We design the service so a failure in one area does not automatically expose everything else.

Account security

Passwords are stored as strong password hashes rather than plain text. Verification and password-reset tokens are single-use and stored in hashed form. Login sessions use secure server-side session records with protected cookies.

Scan infrastructure

Scan requests are validated before they reach the analysis pipeline, and public endpoints are rate limited to reduce abuse. The analysis engine remains separate from the account layer, which also lets visitors run scans without creating an account.

Reporting a security issue

If you find a security problem in SmartRisk, please do not publish sensitive details before we have a chance to investigate. Send the affected URL or endpoint, steps to reproduce, and a brief description of the impact to security@smartrisk.io.

What we need from you

A useful report is usually short and specific. Screenshots, sample requests, timestamps, and proof-of-concept steps are helpful when they are safe to share.
