Fulfillment Policy

How SmartRisk delivers paid access.

Digital service only

SmartRisk is a digital software service. There is no physical product, shipping address, or delivery tracking for SmartRisk subscriptions.

Developer API subscriptions

Paid developer access is provided through the authenticated SmartRisk account. The billing flow creates an invoice for the selected API plan and shows the exact USDT amount, Ethereum Mainnet network, and receiving address.

When access is activated

A payment does not activate a subscription by itself. SmartRisk verifies the configured Ethereum USDT transfer, receiving address, invoice amount, invoice validity, and transaction receipt, then waits for the payment to reach finalized state before recording the settlement and activating the subscription.

Invoice expiry

Invoices are configured with a 30-minute validity period by default. An expired invoice cannot be used to activate a subscription.

Payment problems

Underpayments, overpayments, wrong tokens, wrong recipients, payer mismatches, failed transactions, and ambiguous transfers are not automatically settled. For help with a payment, contact support@smartrisk.io and include the invoice ID and transaction hash when available.

Need to review the payment?

Open the Developer API billing area to view the current invoice and verification status.
